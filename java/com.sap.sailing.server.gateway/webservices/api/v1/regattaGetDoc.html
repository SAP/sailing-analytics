SAP Sailing Analytics Webservices API Version 1.0

URL: /api/v1/regattas/{name}

Description:

The service gets the details of a regatta.
All slashes contained within the {name} parameter must be replaced by "__" (double underscore).

Scoring configuration: scoringSystem contains the scoring scheme enum name. Each series entry includes discardThresholds: null means no series-local discarding rule; an empty array means an explicit local rule allowing no discards. Otherwise, the array contains the numbers of scored races at which successive discards become available; for example, [1] allows one discard after one scored race. Local rules constrain discards to their series. The series also includes oneAlwaysStaysOne and hasCrossFleetMergedRanking, alongside its Medal, score-reset, carry-forward and maximum-discard settings.

Column objects at series[].trackedRaces.fleets[].races[] include isMedalRace, effective numeric factor, nullable explicitFactor (null means use the scoring scheme's default), and oneAlwaysStaysOne (a score of one remains one when scaling). These settings are present for untracked columns too. The effective factor includes any explicit override; Medal defaults depend on the scoring scheme.


Webservice Type: REST
Output format: Json
Mandatory parameters: None
Optional parameters: secret: If the regattasecret is given, further permission checks will be skipped
Request method: GET
Example: https://www.sapsailing.com/sailingserver/api/v1/regattas/Kieler Woche (5O5)
