SAP Sailing Analytics Webservices API Version 1.0

URL: /api/v1/leaderboardgroups

Description:

Creates an empty leaderboard group, the way the AdminConsole does it, optionally with an overall leaderboard. Leaderboards are added to it with /api/v1/leaderboardgroups/{nameOrUUID}/leaderboards. This lets a client build what a series of regattas (e.g., one season of a league) usually is: one leaderboard group holding the regatta leaderboards of all its events, referenced by each of the events (see the leaderboardgroupids parameter of /api/v1/events/createEvent). The request requires the LEADERBOARD_GROUP:CREATE permission for the new group and, if an overall leaderboard is requested, the LEADERBOARD:CREATE permission for the overall leaderboard; the new objects are owned by the current user and the user's default group.


Webservice Type: REST
Output format: Json, a summary of the new group: id, name, displayName, description, hasOverallLeaderboard, overallLeaderboardName (only if the group has an overall leaderboard) and leaderboards (the names of the group's leaderboards)
Mandatory parameters: name: the name of the new group; must be unique
Optional parameters:
description: the group's description; defaults to the empty string
displayName: the group's display name
displayGroupsInReverseOrder: true/false, whether the group's leaderboards are shown in reverse order; defaults to false
overallLeaderboardScoringScheme: the name of a scoring scheme type, e.g. LOW_POINT; if provided, an overall leaderboard named "{name} Overall" is created for the group
overallLeaderboardDiscardThresholds: multiple int values that define the race column indices where discards start to be active in the overall leaderboard; defaults to an empty list
Request method: POST
Example: 
		curl -X POST -H "Authorization: Bearer OuknIUZQyADsqcDDEEyvlr+aBIpB4iVBdjdRYJtdO1w=" "http://127.0.0.1:8888/sailingserver/api/v1/leaderboardgroups?name=1.%20Segel-Bundesliga%202026&displayName=2026&overallLeaderboardScoringScheme=LOW_POINT"
produces output 
		{
		  "id": "5d1c3a0e-8b7f-4c1e-9f0d-2a6b4e8c7d13",
		  "name": "1. Segel-Bundesliga 2026",
		  "displayName": "2026",
		  "description": "",
		  "hasOverallLeaderboard": true,
		  "overallLeaderboardName": "1. Segel-Bundesliga 2026 Overall",
		  "leaderboards": []
		}
Errors:
400 Bad Request: name is missing, or overallLeaderboardScoringScheme is not a known scoring scheme type
401 Unauthorized: the current user lacks the permission to create the group or its overall leaderboard
409 Conflict: a leaderboard group with this name exists already, or an overall leaderboard is requested and a leaderboard named "{name} Overall" exists already
