SAP Sailing Analytics Webservices API Version 1.0

URL: /api/v1/boats

Description:

Creates a boat on its own, without a competitor, and stores it persistently, the same way the boat table of the AdminConsole does it. This is what a regatta whose boats change per race (canBoatsOfCompetitorsChangePerRace) needs: a set of boats shared by all competitors and assigned to them per race, e.g., with /api/v1/mark/addCompetitorToRace. The request requires the BOAT:CREATE permission for the new boat (and the server's CREATE_OBJECT permission); the new boat is owned by the current user and the user's default group.


Webservice Type: REST
Output format: Json, the boat as returned by /api/v1/boats/{id}
Mandatory parameters:
boatclass: the name of the boat class; the boat class is created if it does not exist yet
name or sailid: at least one of the two (see below)
Optional parameters:
name: the boat's name; defaults to the sailid
sailid: the boat's sail number
displayColor: the boat's color as an HTML color, e.g. #ff0000 (url encoded: %23ff0000)
boatId: the ID for the new boat; a string that parses as a UUID is stored as a UUID, any other string as is; a random UUID is used if omitted
Request method: POST
Example: 
		curl -X POST -H "Authorization: Bearer OuknIUZQyADsqcDDEEyvlr+aBIpB4iVBdjdRYJtdO1w=" "http://127.0.0.1:8888/sailingserver/api/v1/boats?name=Black&sailid=1&displayColor=%23000000&boatclass=J%2F70"
produces output 
		{"idtype":"java.util.UUID","id":"0b5e1d2c-6f0a-4f43-9a51-3c6a0e8f1b27","name":"Black","sailId":"1","color":"#000000","boatClass":{"name":"J\/70","typicallyStartsUpwind":true}}
Errors:
400 Bad Request: boatclass is missing, both name and sailid are missing, or displayColor is not a valid HTML color
401 Unauthorized: the current user lacks the permission to create the boat
409 Conflict: a boat with the given boatId exists already
