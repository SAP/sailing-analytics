SAP Sailing Analytics Webservices API Version 1.0

URL: /api/v1/leaderboardgroups/{nameOrUUID}/leaderboards

Description:

Adds an existing leaderboard to an existing leaderboard group, at the end of the group's leaderboards, the same way the AdminConsole does it. The group's name, description, display name and overall leaderboard (scoring scheme and discard thresholds) remain unchanged. Adding a leaderboard that the group already contains changes nothing. The request requires the LEADERBOARD_GROUP:UPDATE permission on the group, the LEADERBOARD:UPDATE permission on the group's overall leaderboard if it has one, and the LEADERBOARD:READ permission on the leaderboard to add.


Webservice Type: REST
Output format: Json, a summary of the group as returned by /api/v1/leaderboardgroups (POST)
Mandatory parameters:
nameOrUUID (path): the name or the ID of the group
leaderboardName: the name of the leaderboard to add
Optional parameters: none
Request method: POST
Example: 
		curl -X POST -H "Authorization: Bearer OuknIUZQyADsqcDDEEyvlr+aBIpB4iVBdjdRYJtdO1w=" "http://127.0.0.1:8888/sailingserver/api/v1/leaderboardgroups/5d1c3a0e-8b7f-4c1e-9f0d-2a6b4e8c7d13/leaderboards?leaderboardName=DSBL%202026%20Act%201"
produces output 
		{
		  "id": "5d1c3a0e-8b7f-4c1e-9f0d-2a6b4e8c7d13",
		  "name": "1. Segel-Bundesliga 2026",
		  "displayName": "2026",
		  "description": "",
		  "hasOverallLeaderboard": true,
		  "overallLeaderboardName": "1. Segel-Bundesliga 2026 Overall",
		  "leaderboards": ["DSBL 2026 Act 1"]
		}
Errors:
400 Bad Request: leaderboardName is missing
401 Unauthorized: the current user lacks one of the permissions listed above
404 Not Found: no group with this name or ID, or no leaderboard with this name
